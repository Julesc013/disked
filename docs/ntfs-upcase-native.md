# Native NTFS table binding

DE-W101 binds the [retained table collector](ntfs-upcase-capture.md) to the
existing held ordinary-image source and owned NTFS reader. Its
[execution contract](../spec/catalog/ntfs-upcase-native-prototype.json) fixes the
identity, profile-prefix, replay, process and resource requirements before testing.

The adapter retains exact table bytes and source context while holding the existing
read-only source and parent identities. Automatic NTFS 3.0 selection validates and
reuses the observed bootstrap prefix before acquiring FILE 10. The parent then
reconstructs the result from retained native responses without reopening the source.
Actual process exit and code/PID/creation/capture identity checks remain required.

A complete table is distinct from a complete observation and from consistent source
binding. Authentic partial evidence remains inspectable; a failed reread grants no
applicability. A live or uncertain worker yields no admitted snapshot. The new kind
is private: public command and inspection admission remain separate work.

Existing file, snapshot and worker owners implement this path. No production file,
directory, source opener or scheduler is added. Physical devices, elevation,
namespace/index/alias/lookup/content admission, other originally scoped platforms
and storage, owner acceptance and release qualification retain their own gates.
