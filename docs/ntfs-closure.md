# Source-bound NTFS record closure

DE-W086 connects captured stream joining to the existing bounded NTFS source,
ordinary-file, owned-worker and public inspection path. Its
[execution contract](../spec/catalog/ntfs-closure-prototype.json) defines exact
list provenance, reachable MFT discovery, full references, quotas, rereads and
projection before implementation/evaluation. Working source/list-binding, ordinary-file,
contained-worker and common frontend cases pass. Clean full native qualification
and implementing-agent review remain pending; no full NTFS admission is claimed.

The original all-platform/storage0.1.0 scope remains. Namespace/content, physical
devices, production writers/recovery, other hosts and owner/release qualification
are separate. No protected source bytes are replaced with synthetic records.
