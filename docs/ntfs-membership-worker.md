# Owned NTFS name-correspondence reader

DE-W097's [execution contract](../spec/catalog/ntfs-membership-worker-prototype.json)
extends the existing reader and immutable snapshot boundary. DE-W096's held-file
implementation is source-integrated. This work adds its contained process and
immutable snapshot boundary; qualification state is recorded below.

The existing snapshot owner seals input, reconstructs exact retained responses,
and checks profile/prefix/domain/report relationships in the parent. The existing
Windows worker owns process identity, finite wait/cancellation, actual exit and
snapshot lifetime. No second opener, parser, process scheduler or provider tree
is proposed. Source-free replay cannot grant current-source or effect authority.

The new private Membership kind binds a target limit and uses distinct request,
frame and capture schema identities. Bootstrap and Directory retain their exact
old wires and defaults. The public inspection decoder remains closed to the new
kind. Common frontend admission is the separate subsequent work, DE-W098.

and complete context/manifest verification; a private 12-group Win32 supplement
is also required. This does not become a full current-suite or full Win32 run.
Earlier request/worker availability failures remain retained and unexplained;
raw failure state must be saved before assertions. No thresholds are relaxed.
