# Native binding for same-capture NTFS name ordering

DE-W104 binds the existing private same-capture observer to held ordinary files,
contained workers and exact parent replay. The [execution contract](../spec/catalog/ntfs-name-order-native-prototype.json)
owns controls, identities, field relationships and qualification requirements.
There is no new opener, process host, parser or public command.

The directory and table must share one captured source/window/epoch. Parent replay
recomputes the complete result from retained responses, including name-order facts
and candidate groups. Self-consistent child hashes alone establish no provenance.

Native agreement and applicability remain separate. A completed mapped-descent
finding remains complete and inapplicable with observed_stable false; it can still
retain agreeing source/metadata/replay fields. This does not establish full NTFS
collation, host case policy, aliases, target membership or lookup.

Existing source policy, budgets, payload bounds, deadlines and retirement rules
stay fixed. Implementation and native qualification are pending. No owner,
hardware, public-command or release acceptance follows from this contract.
