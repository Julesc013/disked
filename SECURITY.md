# Security

DiskEd has no released storage runtime in this specification baseline. Do not use a prototype on customer or valuable physical media. Ordinary development is restricted to fake providers and disposable images.

A public vulnerability-reporting channel and response ownership must be configured before a runtime release. Until the repository owner establishes a private route, do not post customer data, recovery keys, credentials, private disk images or exploitable operational details in public issues. This file deliberately does not invent a security email address or claim Microsoft affiliation.

See the [threat model](spec/safety/threat-model.md), [broker boundaries](spec/safety/broker-and-authorization.md) and [release rules](spec/delivery/licensing-and-supply-chain.md).
