`de2f64dc9c790e4d268334106f7ac22217b4edba`, DE-103 and the continuation grant.
This is implementing-agent review, not owner acceptance or independent safety
qualification. It supports continued local integration; W033 is incomplete.

The portable acquisition core retains no Windows API dependency. Original
capture evidence is outside the immutable plan; its port has three exact fields,
and the core supplies the plan epoch. The v2 map retains that original evidence
across resume. Private file callbacks occur only after destination flush/readback
and complete checkpoint-map flush. A failed observer retains the actual verified
prefix rather than changing a failed operation into completion.

The Windows adapter accepts an externally reviewed definition and reobserves the
same resource/options/capture digest. Admission binds the full operation-store
and code/host/request definition plus four explicit grant categories before
creating metadata. Metadata/source/output name aliases and occupied stores are
refused. Parent resume preparation handles are released before launching a child;
the child revalidates under its own pinned handles before data effects.

The new worker uses the same Windows capability, security, path and aggregate
job helpers extracted from the fake worker. Existing fake behavior, process
budgets, fault controls and all shared native interfaces pass clean regression.
The new private role validates four inherited handles, identities, immutable
request evidence, absent standard handles and job limits before execution. It
cannot inherit generic data-writer handles or restart an existing admission.

Operation history binds worker/attempt/PID-creation epochs and definition identity,
validates ordered bounded records and counter/status relationships, and refuses
complete corrupt or incomplete evidence without repair. Coarse checkpoints are
separate from the per-range acquisition map. Cancellation is a persisted request;
only the returned checkpoint outcome establishes a pause. Provider handles are
released before a quiescent terminal record; quiescence does not erase effect
uncertainty. An unfinished exited worker remains unresolved and is not relaunched.

Clean source evidence verifies generated bytes/map chains independently, separate
submission/reconnect processes, active-writer exclusion, checkpoint cancellation,
new-attempt resume, late admission with the same identity, shared process/memory
limits, operation-record API faults, owned live-worker termination and corruption

171 specification tests (two existing skips), 909 structural checks and 207 exact
build-input hashes pass. The retained initial full run is superseded and has three
failures; it is not used to qualify this source. Artifact hashes and PE/import
observations are retained separately from capability claims.

Logical ordinary-file sharing, local owner/host observations and API flushes
are the qualified profile. This is not authenticated global identity, exhaustive
backing/alias/code-directory-replacement qualification, a filesystem snapshot,
physical fencing, complete runtime-module inventory or power-loss evidence.
Wall-clock observations are not authenticated time; real clock rollback was not
forced. Fixture failure preserves the owned files rather than removing recovery
