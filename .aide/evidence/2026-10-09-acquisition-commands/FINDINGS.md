# W033 command implementation findings

Review corrected the adapter's private reply shape from seven fields to the
worker's actual six-field contract before qualification. Observation is a
completed read even when the operation is still active; execution status and
logical operation outcome remain separate.

Review added full definition/options binding, certain complete coverage and
status/state relationships. A terminal record cannot be projected as running,
and an admitted identity cannot be projected as a pre-admission refusal. Malformed
or throwing execution callbacks produce unknown with available recovery
coordinates rather than a new refusal or automatic retry. Regression spies
exercise these contradictions independently of real worker behavior.

The shared text decoder gained strictly bounded object parameters, and typed
stdio values are subjected to the same canonical depth/value/string limits.
The generator now includes hashes for every local schema reference in the
parameter closure. Spec-tool checks retain their producer/review scope; they do
not establish native implementation or storage qualification.

The working full suite passed all 44 groups before the final response checks.
Its retained log is superseded for final-source qualification. The corrected
command test also passed on working inputs. Fresh-checkout receipts identify the
actual qualified revision and artifact bytes; polling-dependent check counts
can vary while the finite named cases and six verified copies remain fixed.

The separate code/state-directory case verifies successful ordinary-file work
with distinct leaf directories. It does not simulate every possible namespace
replacement or certify physical backing independence. Actual GUI/TUI/shell and
operation-watch integration, public command admission, physical/power-loss/other
platform evidence, independent safety review and owner acceptance remain open.

Generated JSON receipt line endings were normalized to LF before hashing the
retained inventory and verifying staged Git blobs. Raw execution logs preserve
their original bytes. This changes report serialization, not executed results.
