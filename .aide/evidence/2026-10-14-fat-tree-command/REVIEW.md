# Partial implementing-agent review

The runtime owns typed command semantics and uses inward-facing action ports;
native preparation/dispatch stays in platform/windows/storage. No alternate
parser or registry is introduced. Structural schemas are closed; native semantic
checks and independent owned preparation remain additional requirements.
Policy defaults are explicit; OEM selection and fixed offsets are not guessed.
All five exact-digest grants precede invoking execution. Preparation requires
actual worker exit. Failed/malformed execution replies preserve unknown state
and store identity rather than authorizing a replacement.

One proposed operation identity is allocated after grant validation and before
dispatch. Its transient input schema version changes to2; old retained request
and review formats keep their meaning. Fresh native admission binds the same ID.
Unknown/pending ID is not accepted_running. Actual create-only claim and
acknowledgement remain distinct, preventing loss of the reconnect identity.

Parser/form/protocol probe, native regressions and tooling pass. Metadata and
FAT internals remain private implementation dependencies of the command target.
Product composition/frontends/readers/full qualification are still required.
This is implementing-agent review, not independent owner or work acceptance.
