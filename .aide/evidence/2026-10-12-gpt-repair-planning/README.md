Capture hashing includes exact PMBR/header/rounded-array bytes, named image,
positive epoch and geometry. Those declarations do not establish physical identity,
freshness or exclusive access. Source selection is always explicit. Both valid
byte-disagreeing copies require a separate declaration digest even when CRCs collide;
the digest authenticates no operator and grants no authority.

Target GPT metadata must establish a compatible unambiguous footprint. Only target
header-CRC damage is accepted as a header defect; destroyed headers or changed
layout are refused rather than replaced at guessed offsets. Known target arrays
can be reconstructed from the consistent selected copy. Patches cover only exact
advertised array bytes and declared header bytes, omit equal regions and order
changed array before changed header. Preserve source/PMBR/padding and all unrelated
header fields, target locations, names, GUIDs, attributes and after-NUL representation.
The immutable definition/digest owns its byte patches independently of the caller.
Changed capture identity, epoch, geometry or any retained byte invalidates matching.
